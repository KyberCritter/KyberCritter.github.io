# ScottRatchford.com

This is the repository for Scott Ratchford's personal website, built with Jekyll and
hosted on GitHub Pages. All agent tooling (opencode, Claude Code) reads this file.

## Project overview

- Static site generated by Jekyll. Source of truth for content lives in this repo;
  the GitHub Actions workflow builds and deploys `main` to GitHub Pages.
- Layouts and partials: `_layouts/` (`default`, `page`, `post`, `project`) and
  `_includes/` (`nav`, `footer`, `project-card`, `share-buttons`).
- Content: blog posts in `_posts/`, project pages in `_projects/`. Plain HTML pages
  (`index.html`, `about.html`, `blog.html`, `projects.html`, `contact.html`,
  `resume.html`) sit at the repo root.
- Styling: Tailwind CSS compiled from `_src/input.css` into `assets/css/tailwind.css`
  using the standalone Tailwind CLI. Theme colors and content paths live in
  `tailwind.config.js`.
- Site config: `_config.yml` (title, description, collections, defaults, plugins).

## Build and preview

- Serve locally with live reload:

```bash
bundle exec jekyll serve --livereload --port 4000
```

  The site is available at `http://localhost:4000`.

- Build once into `_site/` (also what CI runs):

```bash
bundle exec jekyll build
```

- Recompile the Tailwind stylesheet after editing Tailwind classes:

```bash
# Windows (standalone binary in the repo)
./tailwindcss.exe -i _src/input.css -o assets/css/tailwind.css --minify

# Other platforms
npx tailwindcss -i _src/input.css -o assets/css/tailwind.css --minify
```

- Lint Markdown (config in `.markdownlint.json`):

```bash
npx markdownlint '**/*.md' --config .markdownlint.json
```

## Style

### Markdown

- Include blank lines around lists
- Never end a file in 2 blank lines
- Follow `.markdownlint.json` (MD013 and MD033 are disabled)

### Dates

- Use the current date when updating Jekyll page files
- Blog post filenames use `YYYY-MM-DD-slug.md`; the `date` in frontmatter must match

## Content conventions

### Blog posts (`_posts/`)

Filename: `YYYY-MM-DD-<slug>.md`. Frontmatter:

```yaml
---
layout: post
title: "Post Title"
date: YYYY-MM-DD
categories: [blog]
tags: [topic1, topic2]
---
```

### Project pages (`_projects/`)

Filename: `<slug>.md`. Frontmatter:

```yaml
---
layout: project
title: "Project Name"
description: "One-sentence summary"
categories: [Software, AI/ML, Web]
cover_image: /assets/images/example.jpg
links:
  github: https://github.com/KyberCritter/repo
date: YYYY-MM-DD
featured: true
---
```

- `categories` drive which section a project appears in (Software, AI/ML, 3D
  Printing, Lego, Web). Only projects with `featured: true` show on the homepage.
- Add new images to `assets/images/` before referencing them in `cover_image`.

## Tooling notes

- `scripts/setup.sh` installs Ruby/Node/Playwright dependencies and is designed for
  cloud/CI environments (rbenv at `/opt/rbenv/versions/3.3.6`). On local Windows
  machines, install Ruby via `bundle install` and use `npx playwright`.
- `_site/`, `tailwindcss.exe`, and `vendor/` are gitignored build artifacts.
